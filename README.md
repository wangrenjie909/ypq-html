# 🏀 热血篮球

欢迎来到我的篮球世界！这是一个用 **HTML + CSS + JavaScript** 亲手打造的星空球场网站！

## 🌌 网站特色

- **星空球场视觉**：蓝色渐变天空 + 30颗闪烁星星 + 四角立体球衣
- **Hero 区域**：打字机标语「每一球都全力以赴」+ 浮动篮球头像 + 呼吸发光
- **5大板块**：首页 · 我的偶像 · 球鞋 · 目标 · 球星 · 作品集 · 联系我
- **3个游戏**：石头剪刀布 🪨📄✂️ / 投篮挑战 🏀 / **1000题篮球百科问答** 🧠
- **个人最佳排行榜**：游戏最高分自动保存（localStorage）
- **互动魔法**：换背景色 · 实时时钟 · 显示秘密 · 留言表单验证
- **球星专区**：欧文荣誉榜 + 效力时间线 + 球星名言（中英双语）

## 📁 文件结构

```
热血篮球网站/
├── index.html      ← 网站主文件（双击即可打开）
├── bgm.mp3         ← 背景音乐
└── images/         ← 所有图片素材（球星/球鞋/球衣/队徽）
```

## 🚀 如何打开

直接**双击 `index.html`**，用浏览器打开就能玩！

## 🌍 如何上线（可选）

1. 注册 GitHub 账号（https://github.com）
2. 新建仓库（名字：`你的用户名.github.io`）
3. 上传 `index.html` + `images/` + `bgm.mp3`
4. 设置 → Pages → 开启 → 访问 `https://你的用户名.github.io`
